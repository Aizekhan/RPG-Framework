## Кроки оновлення

1. **Гілка й тег.** Окрема гілка `chore/framework-0.6.0`. У `Packages/manifest.json` заміни `#v0.5.1` на `#v0.6.0`. Відкрий проєкт (або прожени тести в batch mode), щоб пакет оновився; `packages-lock.json` має показати новий хеш.
2. **AI Guidance.** `-executeMethod RPGFramework.GameKit.Editor.AIGuidance.InstallFromCommandLine`. Перевір: оновився блок у `CLAUDE.md`, з'явились `Docs/RPGFramework/recipes/16-*.md` і `17-*.md`, `.gitattributes`, і `.github/workflows/unity-tests.yml` замінено (якщо гра не змінювала його). Якщо workflow гра змінювала — перенеси вручну: крок перевірки секретів має робити `exit 1`, додай крок «Check that tests ran» із шаблону пакета (`Documentation~/AI/ci/unity-tests.yml`).
3. **Секрети CI.** Попроси власника додати `UNITY_LICENSE`, `UNITY_EMAIL`, `UNITY_PASSWORD` (https://game.ci/docs/github/activation). До того CI буде **червоним** — так і має бути.
4. **Git LFS.** `git lfs install`; `git add .gitattributes`. Нові бінарні файли підуть у LFS. Історію (600 МБ) зменшить лише `git lfs migrate import --everything --include="*.fbx,*.png,*.wav,..."` — **це переписує історію**, тільки за згодою власника і коли ніхто інший не має незапушених змін.
5. **Player Settings** (New Game не запускається для наявної гри): `ProjectSettings > Player`: Run In Background = on, Color Space = Linear (перевір вигляд сцен і матеріалів — кольори зміняться), Company Name. **Обережно з Company Name**: він входить у `Application.persistentDataPath`, тобто в шлях збережень. Якщо гравці вже мають збереження, або залиш `DefaultCompany`, або при першому запуску перенеси теку збережень зі старого шляху.
6. **Тести.** EditMode + PlayMode. Очікувано впадуть:
   - **GA14** у `<Game>.Core` — див. «Що переписати»;
   - тести, що покладались на ігнорований `Range` вмінь (тепер вміння поза дальністю відмовляє) — перевизнач `AbilityDistance`;
   - код, що порівнює `CoopProtocol.Version` з 9.
7. **FRAMEWORK-GAPS.md** (з нового правила CLAUDE.md):
   - FG-04, FG-05 (розблоковані ще в 0.5.0) і FG-11: заміни заглушки на API фреймворку, видали заглушки й позначки `// framework-gap`, перенеси розділи в `## Resolved` з `Resolved in: 0.6.0` (FG-04/05 — `0.5.0`, заміна в 0.6.0);
   - FG-10, FG-12: лишаються відкритими.
   - Якщо GA14 знайде щось, що модуль справді не вміє, — новий розділ `FG-13…` з потрібним API, не обхід.
8. **DEVLOG.md**: рядок про оновлення і що перенесено. Коміти малими кроками (`chore:`, `refactor:`), PR, CI.

## Що переписати (GA14 покаже рядки)

Порядок: від найпростішого до великого класу правил (1774 рядки). Розбивай клас на модулі (New Feature, рецепт 02 і 17) по ходу перенесення, а не окремим «великим рефакторингом».

| Зараз у грі | Стає |
|---|---|
| `WeightedId.Pick` для скринь | таблиця луту (Game Setup > New Loot Table або `LootTableBuilder`), відкриття скрині: `ILootGenerator.GenerateLootById(tableId, level, seed: ...)`, предмети `World.GiveItem(playerId, ...)`, золото `World.GiveCurrency(playerId, ...)` для записів `gold` |
| `_random.Next(GoldMin, GoldMax)` для монстрів | запис `gold` (мін/макс кількість) у таблиці луту монстра (`CharacterData.LootTableId`) — кіт сам платить убивці/партії |
| `profile.Gold` | гаманець: `World.CurrencyOf(playerId)`, `GiveCurrency`, `SpendCurrency`. **Збереження:** золото тепер у `PlayerProgress.Currencies`; якщо гра тримає своє `Gold` у власному профілі/секції, при завантаженні старого збереження один раз переклади його `World.GiveCurrency(...)` і прибери поле (версія секції + `Upgrade`, рецепт 12) |
| магазин через `profile.Gold -= price` | трейдер: `Trader.Create("shop", ...)`, `TradeOffer.Create(id, "shop")` + `AddOfferedItem` + `SetGoldAmount(-price)`, зареєструй у `ITraderRegistry` у своєму модулі; кнопка «купити» — `World.TakeOffer(offerId)` (у гостя піде на хост сам). Ціни — у даних/ассетах, не в коді |
| перки на `switch` з ручними кулдаунами | кожен перк — вміння (`AbilityMetadata` з `cooldown`, у `content.Abilities` у `ConfigureSettings`), дія — `World.Abilities.SetEffect("rewind", (caster, target) => track.Rewind(caster, 3f))`; використання `World.UseAbility(id)`; HUD — `World.CooldownLeft(id)` |
| ручні таймери ефектів (отрута, щит, прискорення) | статус-ефекти (`StatusEffectData` у `content.StatusEffects`), `World.Effects.Apply(target, id, source)`, `World.Effects.Has(...)`; прискорення в коопі: ефект із модифікатором Movement рахується хостом сам |
| `x -= dt` у правилах | `ITimerService.Schedule / Repeat / DelayAsync`; спавн хвиль — `WaveSettings`; якщо це рух по трасі (`distance -= speed * dt`), GA14 його не чіпає |
| відстані вздовж траси | один клас простору (`Track`), `protected override float AbilityDistance(int a, int b) => track.Distance(a, b);` у хості, `World.Abilities.ResolveTarget = (caster, ability) => track.NearestAhead(caster);` |

## Кооп

- **Перепідключення:** у `OnCoopHostOpened(host)` підпишись `host.PlayerRejoined += (before, now) => runners.Move(before, now);` — перенеси бігуна, лут, місце в голосуванні зі старого id на новий.
- **Профіль гостя:** `host.ProfileValidator = new MythRunnerProfileCheck();` — обмеж рівень/золото/предмети тим, що можливо в грі, `GuestProfileCheck.Refuse("...")` для неможливого. Двічі за сесію профіль не приймається.
- **Знімок 10 разів на секунду:** заміни `host.SendToAll(snapshot)` на `host.SendLatestToAll(snapshot)`, а останній (кінець забігу) — `host.SendLatestToAll(snapshot, final: true)`; на клієнті `client.On<Snapshot>` → `client.OnLatest<Snapshot>`. Повідомлення має бути класом `NetworkMessage` (поле `Timestamp` фреймворк використовує як порядковий номер — не пиши туди свій час). Якщо знімок великий, наступний крок — зменшити його (лише змінене); якщо для цього бракує фреймворку, запиши розрив.
- **FG-11:** прибери власний пошук адрес; показуй `JoinCode` і `OtherJoinCodes` (стандартна панель F2 уже показує).
- Протокол v10: друзі мають оновити збірку одночасно з хостом.

## Готово, коли

- `#v0.6.0` у manifest і lock; EditMode і PlayMode зелені локально; CI зелений (з секретами), без кроку «NOT RUN».
- GA14 зелений без нових `framework-gap`, крім справжніх розривів із розділом у FRAMEWORK-GAPS.
- У FRAMEWORK-GAPS: FG-04/05/11 у Resolved; FG-10/12 відкриті; нові розриви (якщо є) описані з бажаним API.
- Відгук для фреймворку: що з цього не підійшло на практиці (особливо гаманець/магазин, `AbilityDistance`, `SendLatestToAll`) — новим списком, як цей аудит.
