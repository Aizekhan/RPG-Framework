# MythRunner → RPG Framework v0.7.0: FG-10 і FG-12 закрито

> Для агента MythRunner (Claude Code у репозиторії гри). Спершу заверши оновлення до 0.6.0
> (`Docs/releases/0.6.0-MythRunner-update.md`), якщо воно ще не завершене: 0.7.0 іде поверх нього.
> Деталі API: `CHANGELOG.md` пакета (розділ 0.7.0), рецепти 16 і 17.

## Що нового

| Розрив | Що у фреймворку v0.7.0 |
|---|---|
| FG-10 модуль взаємодії | Модуль `Interaction`: `InteractionPoint(id, kind, radius, prompt, once)`, `IInteractionService` (`Distance` від гри, `NearestFor(player)`, `Interact`, `SetRule(kind, ...)`), `InteractedEvent`, `InteractionModule`. У кіті: `World.Interactions`, `World.NearestInteraction`, `World.Interact(pointId)`, `InteractionPointView` для місць на сцені, E / West на геймпаді, підказка в HUD, `ActionRpgHost.InteractionDistance` (перевизнач), `World.GiveLoot(player, tableId)` для скринь. У коопі все вирішує хост, гості отримують місця від нього |
| FG-12 панелі без prefab + навігація | `StatListPanel` (`BindStats(() => stats)` для будь-якого `IStatContainer`, або `Bind(рядки)` зі своїми значеннями), `EquipmentSlotsPanel` (слоти зі списку гри), `ItemSlotUI.IconOf` (функція іконки) і `ItemSlotUI.Create`, `UIBuilder`, `CodeViewFactory`. У кіті: `ActionRpgHost.Navigation`, `Screens`, `ConfigureScreens(screens)`; Escape / East закриває верхній екран |

**Ламає сумісність:** протокол коопу **v11**: збірки 0.6.0 і 0.7.0 одна до одної не підключаються, оновлюйтеся всі разом. `IActorWorld` отримав `Interactions`, `NearestInteraction`, `Interact` (якщо гра сама реалізує інтерфейс — додай). Клавіші **E** (використати) та **Escape** тепер зайняті кітом: якщо гра їх уже використовує, перепризнач свої або вимкни кітові (див. нижче).

## Кроки

1. Гілка `chore/framework-0.7.0`. У `Packages/manifest.json` заміни `#v0.6.0` на `#v0.7.0`, відкрий проєкт або прожени тести; перевір новий хеш у `packages-lock.json`.
2. Перевстанови AI Guidance (`-executeMethod RPGFramework.GameKit.Editor.AIGuidance.InstallFromCommandLine`): оновляться рецепти 16 і 17.
3. **FG-10 → модуль.** Заміни заглушку взаємодії:
   - скрині, ворота, святилища на сцені — `InteractionPointView` (Id, Kind, Prompt, Radius, Once; `_shownWhileOpen` / `_shownWhenClosed` для вигляду);
   - місця, які гра ставить уздовж траси кодом — `World.Interactions.Add(new InteractionPoint("chest_12", "chest", 2f, "Відкрити", once: true).At(x, y, z))`;
   - відстань по трасі — `protected override float InteractionDistance(int playerId, InteractionPoint point)` у хості. **Увага:** у гостя цей метод теж викликається (тільки для підказки), а класу траси там немає — рахуй з того, що видно на сцені (позиції view), або залиш стандартну відстань, якщо координати сцени відповідають трасі;
   - що робить скриня — підписка на `InteractedEvent` у модулі гри (він працює лише на хості): `if (e.Kind == "chest") World.GiveLoot(e.PlayerId, e.PointId);` (таблиця луту з id скрині або свій id);
   - замкнені місця — `World.Interactions.SetRule("gate", (player, point) => ...)`;
   - анімація/звук відкриття — `InteractedEvent` у view (приходить і на машині гостя).
   - Прибери власний пошук найближчого, свою клавішу й підказку, позначки `// framework-gap: FG-10`.
4. **FG-12 → панелі.** Заміни свої панелі-заглушки:
   - характеристики — `StatListPanel` з `BindStats(() => runner.Stats, stat => назва)` або `Bind(new[] { ("Золото", (Func<string>)(() => World.CurrencyOf().ToString())) })`;
   - спорядження — `EquipmentSlotsPanel.Bind(твій список слотів, slot => що в ньому, item => іконка)`; клік — подія `SlotClicked`;
   - екрани реєструй у хості: `protected override void ConfigureScreens(CodeViewFactory screens) => screens.Register<StatListPanel>("stats", p => p.Bind(...));`, відкривай `Navigation.NavigateToAsync("stats")`. Екрани з prefab — `PrefabViewFactory` як `screens.Fallback`;
   - Прибери позначки `// framework-gap: FG-12`.
5. Якщо гра вже використовує E чи Escape: свій `PlayerController` (успадкуй кітовий) або перепризнач свої дії. Якщо так не виходить — запиши розрив (потрібна настройка клавіш кіту).
6. Тести EditMode + PlayMode, CI.
7. **FRAMEWORK-GAPS.md:** FG-10 і FG-12 перенеси в `## Resolved` з `Resolved in: 0.7.0`. Якщо щось із цього не підійшло — новий розділ `FG-13…` з потрібним API, а не обхід.
8. DEVLOG.md: рядок про оновлення. Малі коміти, PR.

## Готово, коли

- `#v0.7.0` у manifest і lock; тести й CI зелені.
- У грі немає власного коду взаємодії й панелей-заглушок; FG-10, FG-12 у Resolved.
- Відгук для фреймворку новим списком: що не підійшло на практиці (особливо відстань для підказки в гостя, клавіші E/Escape, панелі на легасі-шрифті замість TMP).
