# Framework gaps

What this game needed from RPG Framework and did not find. Every `// framework-gap: <id>` marker in the code has a
section here (architecture rule GA12). This list is the framework's backlog with proof: it is how the framework learns
what real games need. After every framework update, check each open gap against the new version's CHANGELOG: when the framework gains
the feature, replace the stand-in with it, delete the stand-in and move its section to "Resolved" with the version.
